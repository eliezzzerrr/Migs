# Reviews

Weekly review files generated by `workflows/weekly-review.md`.

## Filename

`YYYY-Www.md` where `Www` is ISO week number (e.g. `2026-W21.md`).

## Cadence

- Default: every Sunday evening PHT
- Mid-week: allowed if >10 trades in 3 days

## What's in each review

- Headline numbers for the week
- Pattern performance breakdown
- Proposed pattern splits / promotions / gates
- Proposed doctrine adjustments (REQUIRE USER APPROVAL — never auto-applied)
- Action items for next week

## Workflow

Triggered by: user says "weekly review" or "review the week" or it's a scheduled run. See `workflows/weekly-review.md` for the full procedure.
