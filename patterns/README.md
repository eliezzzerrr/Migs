# Patterns

This directory holds the pattern library. One `.md` file per pattern + a single `stats.json` index.

## Files

- `stats.json` — live aggregated stats per pattern + global metrics (auto-generated by `scripts/update_stats.py`).
- `{id}.md` — one per pattern. Frontmatter defines the match rule and status; body holds notes.

## IDs

Lowercase descriptive slugs. Current: `buy` (Hybrid BUY), `sell` (Hybrid SELL). Future sub-patterns added when data justifies a split (e.g. `buy-london`, `sell-counter-trend`); slugs are picked at weekly review.

Historical note: pattern IDs `"01"` (BUY) and `"02"` (SELL) were renamed to `"buy"` / `"sell"` on 2026-05-22 for clarity. `update_stats.py` still accepts old numeric IDs in journal frontmatter and normalizes them on read.

## Statuses

- `active` — agent matches trades against this pattern; not gated
- `gated` — pattern WR <40% over ≥5 trades; future signals matching this auto-NO-TRADE
- `retired` — merged into another pattern or no longer relevant; kept for history

## Don't edit `stats.json` by hand

Always regenerate from the journal: `python scripts/update_stats.py`. The script reads every journal entry's outcome and recomputes from scratch — idempotent.
